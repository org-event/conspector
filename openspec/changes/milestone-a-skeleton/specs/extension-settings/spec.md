# Spec Delta

## Purpose

Popup Chrome-расширения хранит настройки пользователя (адрес локального сервера) и показывает состояние соединения с сервером, чтобы пользователь мог начать запись только при доступном сервере.

## ADDED Requirements

### Requirement: Server URL persistence
Popup SHALL содержать поле «Адрес сервера» с дефолтным значением `http://127.0.0.1:8765`; введённое значение SHALL сохраняться в `chrome.storage` и восстанавливаться при каждом открытии popup.

#### Scenario: Значение сохраняется между открытиями
- **WHEN** пользователь вводит адрес сервера и закрывает popup, затем открывает popup снова
- **THEN** поле содержит ранее введённый адрес

#### Scenario: Значение по умолчанию
- **WHEN** пользователь ещё ни разу не сохранял адрес сервера
- **THEN** поле показывает `http://127.0.0.1:8765`

### Requirement: Server availability indicator
Popup SHALL проверять доступность сервера запросом `GET {serverUrl}/health` (при открытии popup и после сохранения адреса) и показывать пользователю результат: сервер доступен или недоступен.

#### Scenario: Сервер доступен
- **WHEN** popup открыт и сервер отвечает на `GET /health` с `ok: true`
- **THEN** popup показывает индикатор «сервер доступен»

#### Scenario: Сервер недоступен
- **WHEN** popup открыт и сервер не отвечает (нет соединения или ошибка HTTP)
- **THEN** popup показывает индикатор «сервер недоступен»
