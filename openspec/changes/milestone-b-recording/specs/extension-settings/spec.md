# Spec Delta

## Purpose

Настройки popup дополняются параметрами записи и цели захвата поверх адреса сервера.

## ADDED Requirements

### Requirement: Recording controls in popup
Popup SHALL содержать элементы «Старт» и «Стоп» и текстовый статус записи (не записывает / запись / загрузка / ошибка), в дополнение к полю адреса сервера и индикатору health.

#### Scenario: Элементы на месте
- **WHEN** пользователь открывает popup
- **THEN** видны serverUrl, индикатор сервера, цель захвата, кнопки Старт/Стоп и статус

### Requirement: Persist capture pattern
Ключ `captureUrlPattern` (string, дефолт пустая строка = любая страница) SHALL храниться в `chrome.storage.local` рядом с `serverUrl`.

#### Scenario: Дефолт паттерна
- **WHEN** пользователь ещё не задавал паттерн
- **THEN** поле паттерна пустое и запись разрешена для активной вкладки (с учётом прочих проверок)
